# Personal Expense Tracker

A modern desktop application built with Python to help manage and visualize personal finances. 

## Features
* Add, delete, and view daily expenses.
* Modern user interface built with `ttkbootstrap`.
* Interactive pie chart visualization using `matplotlib`.
* Local SQLite database for secure and fast data storage.
* Export data directly to CSV for Microsoft Excel or Google Sheets.

## Technologies Used
* Python
* Tkinter & ttkbootstrap
* SQLite3
* Matplotlib

## How to Run
1. Clone the repository.
2. Install the required libraries: `pip install matplotlib ttkbootstrap`
3. Run the application: `python main.py`
